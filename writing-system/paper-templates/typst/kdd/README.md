### What to use instead for drafting

`typst/ieee/charged-ieee` is *not* an ACM look. For drafting, `typst/generic/` is more honest.

### Official LaTeX for submission

`latex/kdd/` — ACM `acmart` in `sigconf` format.

This directory contains a note rather than a fabricated template. Nothing here
is a mock-up of a venue style, and nothing here is presented as official.
