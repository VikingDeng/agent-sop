### What to use instead for drafting

`typst/cvpr/` (blind-cvpr) is visually the same two-column CVF layout and is the right stand-in for drafting.

### Official LaTeX for submission

`latex/iccv/` — CVF author kit (cvpr-org/author-kit) — the same kit covers CVPR, ICCV and WACV; select the ICCV style as the kit documents.

This directory contains a note rather than a fabricated template. Nothing here
is a mock-up of a venue style, and nothing here is presented as official.
