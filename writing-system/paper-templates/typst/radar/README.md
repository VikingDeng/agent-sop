# IEEE Radar Conference / IGARSS / IEEE TGRS / GRSL / TAES / IEEE Transactions on Radar Systems

## Typst: no reliable template

**No IEEE-endorsed Typst template exists for any of these. The whole IEEE family is covered by the LaTeX `IEEEtran` class and the IEEE conference template, and IEEE does not accept Typst submissions.**

### What to use instead for drafting

`typst/ieee/charged-ieee` or `typst/ieee/bamdone-ieeeconf` for drafting only. Note that `typst/radar/isprs/` DOES contain a real Typst template (magic-isprs) — that one is for ISPRS remote-sensing venues, not IEEE.

### Official LaTeX for submission

`latex/radar/` — IEEE templates: the IEEE conference template (for RadarConf / IGARSS) and `IEEEtran` (for TGRS / GRSL / TAES / T-RS journals).

This directory contains a note rather than a fabricated template. Nothing here
is a mock-up of a venue style, and nothing here is presented as official.
