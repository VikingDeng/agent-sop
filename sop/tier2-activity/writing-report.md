# SOP-writing-report: 报告 / 总结写作

- **层级**: tier2-activity
- **落实纪律**: P2(数据/论断经独立核验)+ P3(没依据宁可不写)+ P4(每个外部论断绑来源)
- **绑定骨架**: 无
- **通用性档位**: U0(报告写作流程普适)
- **版本**: v1

## 触发条件

需要写报告/总结/周报/分析(含对外结论、数据、引用)时。

## 前置条件

数据与来源可核验;报告目的与受众明确。

## 依赖 SOP

无。

## 步骤

1. 先定目的/受众/关键结论/非目标(不下哪些结论),再组织内容。
2. 每个数据/事实论断标来源;关键数据经独立核验(P2:第二来源或原始数据复算,不单点采信)。
3. 区分事实与观点:结论要能由文中证据支撑,不夸大、不外推超出数据支持的范围。
4. 外部引用绑来源链接/出处(P4);无出处的"据说/大概"不进正式结论。
5. 终稿自查:每个论断问"依据是什么、够不够支撑"。

## 门禁

[REVIEW] 每个论断有据;无依据不写数;结论不超出证据支持范围。
[REVIEW] 产出符合 → PROSE_STANDARD.md。

## 完成判定

- 目的/受众/关键结论已定;
- 每个数据论断有可核验来源且关键项经独立核验;
- 结论均有文中证据支撑(二值核对)。

## 失败处理

遵守 P3:某数据找不到可靠来源 → **宁可不写或标注"数据缺失"**,绝不编一个数字/引用凑数(造假是最严重的 P3 违规);结论缺乏证据支撑 → 降级为"待验证假设"或删除,不得包装成确定结论;来源存疑 → 标注存疑,不静默当权威引用。

## 产物

一份报告:目的/受众/结论 + 有据的数据与论断(来源可核验)+ 证据支撑的结论。
