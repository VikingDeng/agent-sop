# SOP-statistics-oracle: 统计正确性关(结论前的独立复算)

- **层级**: tier1-skeleton
- **落实纪律**: P2(统计结论用独立路径复算,禁被测分析自证)+ P3(检验前提不满足/算不出即报,不硬下结论)+ P4(每个统计结论绑数据+方法+代码版本)
- **绑定骨架**: research
- **通用性档位**: U1(统计不变式通用;检验选型/容差/校正方法以 {参数} 由项目注入)
- **版本**: v1

## 触发条件

`[信号自触发]` research 骨架中,多次实验结果已聚合(如多 seed 分布已由 run-experiment 产出),**即将下一个比较性/显著性结论**时(如"A 优于 B""提升显著""相关成立")——下结论前必过本关。
`[显式]` 作者要求"做显著性检验 / 算置信区间 / 核对统计是否正确"。

## 前置条件

- 待下结论的原始数据已就位:每个条件的多次观测(≥ `{N_SEEDS}`,由 reproduce-result / run-experiment 提供),非单点;
- 已声明本次要下的**统计结论**(比较谁和谁、方向、判据),防事后挑检验凑显著(P1 的延伸:结论先注册);
- 已读红线清单:references/statistics-redlines.md。

## 依赖 SOP

## 步骤

1. **登记结论与检验设计(先设计后看数)**:写下本次结论、原假设/备择、选用的检验 `{TEST}` 及选它的理由(数据配对与否、分布假设、方差齐性)、显著性水平 `{ALPHA}`、多重比较个数 `{M}` 与校正方法 `{CORRECTION}`。此登记在**看聚合结果之前**完成,防 p-hacking。
2. **红线预扫(阻断)**:对分析脚本与结论过 references/statistics-redlines.md 每一条。命中任一即拦,回到步骤 1 改设计,不带病往下走。
3. **算三件套,不是只算 p**:报告必须同时含 ① 效应量(如 Cohen's d / 相对提升 %)、② 置信区间、③ 检验 p 值——三者缺一不合格(只报 p 不报效应量是 CDR 同类硬伤)。
4. **独立 oracle 复算(阻断,P2)**:用一条**与主分析独立的实现路径**重算步骤 3 的关键量。独立性要求同 build-oracle:不同库或不同方法(如主分析 scipy.ttest → oracle 用置换检验/bootstrap 重抽样;主分析自写 → oracle 用成熟库)。两条路径结论(是否显著、区间是否重叠)一致才放行;不一致 → 判主分析不可信,回步骤 1。
5. **检验前提核对**:核对 `{TEST}` 的前提在数据上成立(正态性/独立性/方差齐性/样本量下限)。前提不满足 → 换非参数检验或报告"前提不满足,不下参数结论",不得无视前提硬套(P3)。
6. **NaN/inf 闭环**:统计流程中出现 NaN/inf(缺失、除零、log(0))→ 硬失败报错并定位来源,禁止 dropna 后静默继续或用 0 填充冒充完整(CDR 实测缺陷,红线清单亦收录)。
7. **归档(P4)**:结论 + 检验设计登记 + 三件套 + oracle 复算对拍结果 + 前提核对,写入 `{STATS_REPORT}`。证伪/不显著如实记,不藏。

## 门禁

> gate 分型见 → no-fallback-review.md。本 SOP 两关**均为阻断型**(统计错误直接决定结论真伪,无信号档)。

[SCAN] 红线清单可机检项:单侧/双侧未声明、只报 p 无效应量、bootstrap-CI 的 p 冒充检验 p、多重比较无校正、NaN 未闭环的正则/AST 扫描。
[REVIEW] 审稿式必问:"这个 p 是有效检验 p 还是从 CI 反推的?检验前提在这份数据上成立吗?换独立方法重算结论还一致吗?"
[RUNTIME] oracle 复算作为一个可运行步骤产出二值 pass/fail;fail 即拦。

## 完成判定

- 结论 + 检验设计在看数前登记(二值:登记文件时间戳早于聚合结果);
- 三件套(效应量+CI+p)齐全;
- 独立 oracle 复算结论与主分析一致(二值 pass);
- 红线清单零命中;
- 前提核对通过或已如实降级为非参数/不下结论。
可查:{STATS_REPORT} 存在 + oracle 对拍 pass + 红线扫描零命中。

## 失败处理

遵守 P3:oracle 复算与主分析不一致 → 判主分析结论不可信、作废,不得"取对我有利的那条";检验前提不满足 → 换检验或不下参数结论,不得无视前提硬报显著;p 值来自 bootstrap-CI 反推 → 判为无效检验 p,必须改用正式检验(如置换检验),不得沿用;NaN/inf → 硬失败定位来源,禁 dropna/填 0 静默继续;样本量不足以支撑所选检验 → 报告"证据不足,不下结论",不得凑数下结论。**任何一条失败都不产出"显著/优于"类结论。**
